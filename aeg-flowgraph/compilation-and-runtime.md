# AEG FlowGraph：编译与运行生命周期

[返回架构总览](<../AEG FlowGraph Architecture.md>)

输入来源、执行实例、结果状态、取消、资源版本和摘要以 [作者与执行契约](authoring-and-execution-contract.md) 为准；本分册展开 Frame/Render profile 的编译器、预览、应用和 Runtime Inspect 流程。Logic/Flow profile 复用身份、版本和诊断原则，但其运行对象是 FlowInstance/StateStore/Transition，不是 RenderPass。

## 1. 从作者图到运行图

FlowGraph 将过程固定为：

```text
作者图草稿 → 图结构解析 → 端口/资源校验 → 数据流编译
       → 目标准备快照 → 安全点应用 → 实际执行图
```

作者图是唯一可编辑真相。编译计划和实际执行图是派生结果，不能在运行检查中修改。执行图可以因为裁剪、合并、资源复用、队列安排和平台限制与作者图不同，但每个差异都应有来源和原因。

## 2. 编译步骤

### 2.1 解析

确认资产版本、节点身份、类型目录版本、子图引用、端口 ID 和布局数据可读取。未知类型不删除数据，转换成占位节点；未知端口保留旧边并报告迁移错误。

### 2.2 图接口展开

解析 Graph Input/Output，将 Frame/Render Feature/CompositePass 的公开端口映射到调用节点。Logic/Flow 子图另外映射 Flow/State/Transition 的公开契约；私有端口不可跨图引用；接口版本变化产生迁移预览。重复实例使用同一子图定义但拥有各自参数和绑定。

### 2.3 类型与数据验证

逐条检查端口方向、DataType、Domain、Scope、Access、Lifetime、格式、来源模式和节点声明的连接基数。对节点已声明的 Variadic/Array 端口检查最小/最大数量、空集合、槽位类型和顺序；对固定端口拒绝新增来源；对 Asset/Default/Context 来源检查绑定身份、导入状态和目标可用性；对 Merge/Compose 检查各自定义的输入是否满足合并规则。

### 2.4 拓扑和资源计划

根据数据边生成 DAG；每条 `A 输出 → B 输入` 同时表示 A 的结果先产生、B 再执行。A、C 都连接到 B 时，B 等待两者满足端口规则，但不额外推导 A 与 C 的先后。没有普通数据边的 Asset/Default/Context 来源只作为资源准备或运行上下文条件，不生成虚假的上游执行节点。检查循环、孤立副作用、未使用输出和没有可用来源的必需输入。随后分析资源生命周期、唯一生产者、多消费者、队列切换和同步需要。每次目标调用生成 `ExecutionInstanceId`，并把它带入 ResourceValueVersion、异步请求和缓存键；画布坐标、节点创建顺序和未声明的数组顺序不参与排序。

### 2.5 目标准备

目标可以是编辑器预览、Play 会话、指定 View/World 或 Cook 平台。准备阶段解析目标提供的外部资源、格式、设备能力和队列；不满足时返回目标级错误，作者图仍可保存。

## 3. 诊断类型

| 诊断               | 示例                                                | 处理                                                 |
|--------------------|-----------------------------------------------------|------------------------------------------------------|
| 必填输入无可用来源 | `Bloom.SceneColor` 无数据边、无合法资产或上下文绑定 | 错误，定位端口，提供上游候选、资产选择或 Graph Input |
| 外部资源绑定缺失   | 端口声明允许 Asset，但 AssetId 不存在或导入失败     | 错误，修复资产引用或改用合法数据边                   |
| 类型不匹配         | Color 输出连接 Depth 输入                           | 错误，建议合法 Adapter                               |
| 多连单值           | Single 输入已有两个来源                             | 错误，选择一个或使用节点定义的替换/合并流程          |
| 未声明输入         | 试图向节点增加类型未定义的端口                      | 错误，需选择已有端口或更新节点类型定义               |
| Variadic 契约缺失  | 节点未声明数量、空集合或上限                        | 错误，不能由编辑器临时扩充输入                       |
| Scope 不可见       | Frame 端口读取 World 私有数据                       | 错误，建议桥接 Artifact                              |
| 资源格式冲突       | RGBA8 接入 RGBA16F 必填端口                         | 错误或推荐转换节点                                   |
| 普通循环           | 当前帧输出回接上游                                  | 错误，建议 History/迭代节点                          |
| 副作用无收据       | 写入 Pass 没有 Receipt/Token 输出                   | 错误，不能保证执行                                   |
| 无消费者输出       | 节点结果没有进入输出或副作用                        | 警告；用户可保留为草稿                               |
| 队列/阶段不兼容    | Compute Pass 需要未开放队列                         | 错误，显示能力来源                                   |
| 运行时裁剪         | 节点结果没有影响任何输出                            | 运行检查信息，作者图不删除                           |
| 运行时合并         | 多个 Pass 被平台合并                                | 运行检查信息，显示来源列表                           |
| 模块缺失           | 类型目录或实现模块不存在                            | 离线错误，保留节点和连接                             |

每条诊断包含对象路径、端口/边、快照、稳定编号、解释、可能修复动作和是否阻断 Compile/Preview/Apply。用户可以在 Diagnostics 中只看当前图、当前节点的上下游或所有阻断错误。

## 4. 编译状态

| 状态                   | 说明                     | 可做动作                       |
|------------------------|--------------------------|--------------------------------|
| Draft                  | 当前作者图未编译或已修改 | 增删连线、保存、请求 Compile   |
| Compiling              | 正在生成计划             | 继续编辑新草稿、取消可取消阶段 |
| Compiled with Errors   | 有阻断错误               | 编辑、保存、查看上一可用预览   |
| Compiled with Warnings | 可生成计划但有风险       | 保存、预览、应用，警告持续可见 |
| Prepared               | 目标已生成可执行快照     | Apply/Preview                  |
| Applied                | 目标已切换到快照         | Runtime Inspect                |
| Stale                  | 作者图或目标已变化       | 重新 Compile                   |
| Unknown/Offline        | 类型或模块不可用         | 离线编辑、迁移、导出诊断       |

“Compiled”只描述当前语义快照，“Saved”只描述磁盘，“Applied”只描述目标运行态；顶部同时显示三者版本。

## 5. 保存、预览和应用

### 5.1 保存

保存作者图、节点参数、端口连接、子图引用、公开接口和布局。可以保存断线和错误，以便暂存工作；没有成功解析的未知字段时先保留原文档扩展数据，不能把它序列化成空节点。写入采用临时文件校验、完整性摘要、flush/关闭后原子替换，并保留上一个可恢复版本；半写文件和摘要不匹配不能进入 Compile。

### 5.2 预览

预览从当前作者草稿生成隔离快照，在编辑器目标中准备。警告不被隐藏；阻断错误禁用预览。预览成功在安全帧边界应用，失败继续使用最后可用版本。预览快照不自动写为资产默认，也不自动覆盖项目引用。上游失败、取消或跳过不会自动退回 Default/Asset；只有端口契约声明并经用户确认的 FallbackPolicy 才能切换来源。

### 5.3 应用

应用要求目标准备成功。配置、资源绑定、输出选择、队列计划和必要的历史重置必须作为一个事务切换。失败时回滚运行态而不撤销作者图；过期异步准备结果不得覆盖较新的应用。取消发生在提交前时释放未提交资源，已提交的 External SideEffect 按其 CommitPolicy 处理，不能伪造回滚成功。

### 5.4 停止预览

停止预览解除临时覆盖，恢复预览前的目标配置，保留作者草稿和诊断。若目标已经销毁，恢复动作只清理仍存在的绑定，显示无法恢复的目标项，不伪造成功。

## 6. Runtime Inspect

运行检查显示实际执行图的 WorkItem、RenderGraph Pass、Resource、队列和数据关系，支持按
Feature Definition/Node/Instance/Process/Invocation、Frame/Render 的兼容 Pipeline/Pass、
Resource、类型、裁剪和合并过滤。选择节点时显示：

当前编辑器首版已提供 `Runtime Inspect` 只读入口：它从活动 `ExecutionPlan`（当前实现为
`PipelinePlan` 兼容投影）显示计划版本、执行节点稳定 ID、依赖入出度、依赖类型、合成节点
标记，以及能够解析时的作者 Feature/Node 来源、GraphAsset、GraphVersion 和
SemanticDigest。该入口不修改作者文档。逐资源别名、队列屏障、裁剪/合并原因、性能采样和
完整 Definition/Instance/Process/Invocation 信息需要对应运行采集协议后再开放，不能用计划摘要冒充。

- 作者来源资产、图层、子图和 NodeId。
- 实际输入/输出资源、格式、生命周期和别名。
- 被裁剪、合并、延迟或改队列的原因。
- 执行耗时、内存和同步数据；没有采集时显示不可用。
- 运行快照、目标、ExecutionInstanceId、AttemptId、Frame/View/World 和帧号。

如果一个运行节点由多个作者节点合并，显示来源列表；如果来源映射丢失，标记为“来源映射错误”，不一律声称是引擎生成。运行检查中的过滤、布局和折叠不回写作者图。

## 7. 版本、模块和接口迁移

节点类型、端口、子图接口和资源 Schema 都有版本。更新模块后：

1. 读取旧版本并建立字段/端口映射。
2. 自动迁移无歧义的参数和连接。
3. 对新增必填端口创建“来源未满足”诊断；如果新契约声明了合法默认值或 Asset Binding，显示待确认的绑定候选，但不自动连接“相似”资源。
4. 对删除/重命名端口保留未知边和原始数据。
5. 显示迁移预览，允许复制资产或导出原始文档。
6. 迁移结果经重新编译和保存后才成为新版本；失败仍使用最后可用运行态。

子图接口变更影响所有调用实例，迁移面板列出调用路径、新增输入、断开的边和默认值；用户可以一次确认，也可以逐实例处理。

## 8. 代码节点重载与契约回流

自定义代码节点的源码编辑发生在外部 IDE，但编辑器仍是节点契约和作者图的审查入口。IDE 保存后必须经过“构建模块 → 重新导出 TypeCatalog → 比较 Node Contract → 迁移预览 → 重新编译图”的流程，不能让源码修改直接覆盖 `.aegpipe` 或当前运行态。

| 回流状态            | 编辑器表现                   | 图和运行态行为                             |
|---------------------|------------------------------|--------------------------------------------|
| Source Unchanged    | 契约和源码版本一致           | 正常编译和应用                             |
| Source Changed      | 源码较新，目录仍是旧版本     | 保留上一次有效契约；提示需要构建/重载      |
| Module Build Failed | 模块构建失败                 | 保留节点和连接；可离线编辑；禁止使用新实现 |
| Contract Diff       | 新旧端口、参数或执行规则不同 | 显示影响实例、断边和迁移选项               |
| Reloaded            | 新契约已加载                 | 受影响图进入 Stale，必须重新验证           |
| Runtime Pending     | 图已重新准备但尚未应用       | 继续使用上一次 Applied 快照                |

契约兼容性由 《节点目录与扩展机制》定义：可选输入和说明变化可以保留旧行为；新增必填输入、删除端口、改变类型、输入数量、来源模式、资源生命周期、阶段、队列或输出含义时，必须提高版本并阻断未完成迁移的图。若新增必填输入同时声明了合法默认值或 Asset Binding，迁移仍需显示待确认的来源绑定，不能自动连接“相似”资源。Runtime Inspect 继续显示当前运行态实际使用的契约版本和源码映射。

## 9. 冲突与并发

多个窗口打开同一资产共享作者会话和撤销历史。不同资产拥有独立会话。磁盘发生外部修改时使用共同基础版本做三方合并；节点身份、端口、子图接口、输出、ActiveSource、SlotId、GraphVersion 和删除/编辑冲突必须逐项确认。语义冲突保留双方原值并阻断 Compile，不能按最后写入时间静默裁决。

同一目标同时只有一个应用事务。多个目标可以各自准备，但每个目标有独立快照。用户继续编辑时产生新草稿，正在准备的快照冻结不变；准备完成后只有仍匹配的快照才允许应用。

## 10. 性能目标

- 画布平移、缩放和移动节点不触发全图编译。
- 参数改动先局部校验，用户点击 Compile 才生成完整计划。
- 大图采用增量诊断、可见区域渲染、端口分组和按需展开子图。
- 编译显示解析、接口展开、类型验证、拓扑、资源、目标准备六个阶段，并提供取消或等待原因。
- Runtime Inspect 大图先显示拓扑和节点摘要，详细资源/性能数据按选择加载。
